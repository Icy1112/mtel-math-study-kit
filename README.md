# MTEL Math 63 Study Kit

A free study kit for the **MTEL Mathematics (Field 63)** test, which licenses math teachers for grades 8–12 in Massachusetts. Field 63 replaced the old Field 09.

**Use it online:** <https://icy1112.github.io/mtel-math-study-kit/>

## The test

- 85 multiple-choice questions + 2 open-response (written) tasks. 4 hours, on a computer.
- Passing score: 240 (a scaled score, not a percent).
- An on-screen scientific calculator and a formula sheet are given.
- No penalty for wrong answers, so never leave a question blank.
- Official page: <https://www.mtel.nesinc.com/TestView.aspx?f=HTML_FRAG/MA063_TestPage.html>

## What is in this folder

| File | Use it to |
|---|---|
| `index.html` | **Start here.** The study app: Plan checklist, Concepts (plain words, short videos, interactive visuals, 3 worked examples per topic), Flashcards, Practice (drills, 20-question diagnostic, 85-question timed mock) and Open-response practice. Open it in any browser. |
| `visuals.js` | The 18 interactive "See it" visuals (sliders and graphs), drawn with plain canvas. |
| `study-plan.md` | Read the 8-week plan, the study method, the 4-week triage track and test-day pacing. |
| `resources.md` | Find the best free link for each topic (official MTEL, Khan Academy, OpenStax, Paul's Notes, 3Blue1Brown) and 62 short videos by topic. |
| `data/` | The content the app shows. You can edit or add questions here. |

## How to start (day 1)

1. Open `index.html`. Go to **Practice → Diagnostic (20)** and take it without study.
2. Open the **Plan** tab and tick off each day as you finish it.
3. For each new topic, follow the routine: **Watch** a short video → **See it** (move the sliders) → step through the **Examples** → drill.
4. Keep a paper error log. Redo it every Sunday.

## Notes

- The practice questions are original and written for this kit. They are not official MTEL questions. A practice % is only a rough guide: aim for 75% or more before test day.
- Progress (checkboxes, flashcard boxes, scores) is saved in your browser only. If you clear site data or change browsers, it resets.
- Use the official full practice test in week 7. It is the best predictor you have.
